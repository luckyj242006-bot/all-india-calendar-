# All India Calendar & Vedic Panchang 2026-2027

A modern, responsive, animated multi-lingual Indian Calendar & Panchang web application inspired by `luckyj242006-bot.github.io/all-india-calendar-`.

## 🚀 Key Improvements & What's New

### 1. 8 Regional Indian Languages Supported
Full localization across weekday names, month names, lunar tithis, nakshatras, festivals, and UI controls:
- **English**
- **हिन्दी (Hindi)**
- **বাংলা (Bengali)**
- **தமிழ் (Tamil)**
- **తెలుగు (Telugu)**
- **ગુજરાતી (Gujarati)**
- **मराठी (Marathi)**
- **ಕನ್ನಡ (Kannada)**

### 2. Enhanced Animations & Visual Design
- **Interactive SVG Moon Disc**: Dynamic waxing and waning lunar disc accurately calculated from Sun-Moon angular elongation.
- **Micro-interactions & Ripple Effects**: Smooth hover and touch feedback on all interactive day cells and buttons.
- **Celebration Confetti**: Festive confetti animation (`canvas-confetti`) when viewing major festivals or saving reminders.
- **Theming**:
  - 🌿 **Royal Emerald** (Default)
  - 🕉️ **Vedic Saffron**
  - 🌙 **Midnight Dark Mode**

### 3. Essential New Features Added
- **Shubh & Ashubh Muhurat Timings**:
  - **Rahu Kaal (राहु काल)**: Dynamically calculated based on local sunrise/sunset and day-of-week segment.
  - **Abhijit Muhurat (अभिजीत मुहूर्त)**: Calculated around local solar noon.
  - **Yamaganda (यमगंड)**.
- **Festival Search & Category Filter**:
  - Search any festival across 2026-2027 in real-time.
  - Filter by category: **All**, **Major Festivals**, **Vrats & Ekadashi**, **National Holidays**, **Regional Festivities**.
- **Calendar Export (.ics)**:
  - One-click **"Add to Calendar (.ics)"** export compatible with Google Calendar, Apple Calendar, and Outlook.
- **WhatsApp & Social Panchang Card Sharing**:
  - One-click copy or direct native share formatted with emojis, daily tithi, sunrise/sunset, and auspicious timings.
- **Expanded Indian & Global Cities**:
  - New Delhi, Mumbai, Kolkata, Chennai, Bengaluru, Hyderabad, Ahmedabad, Pune, Jaipur, Varanasi, Lucknow, Patna, Guwahati, London, New York.
- **Multi-regional Calendar System**:
  - Gregorian
  - Vikram Samvat
  - Shaka Samvat (National Civil)
  - Tamil Solar Calendar
  - Bengali Solar Calendar
  - Gujarati Samvat (Sud/Vad system)
  - Purnimanta & Amanta lunar month systems.

## 🛠️ How to Run Locally

You can open `index.html` directly in any web browser, or serve it with Python/Node:

```bash
# Python
python -m http.server 8080

# Or npx serve
npx serve .
```
